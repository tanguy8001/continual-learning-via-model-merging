# State-of-the-Art Methods in Class-Incremental Learning (CIL)

## Overview of Class-Incremental Learning Challenges 
Class-Incremental Learning (CIL) is the paradigm where a model learns new classes in sequential tasks without revisiting old data, striving to retain past knowledge while acquiring new concepts. The major challenge is *catastrophic forgetting, i.e. the model’s accuracy on earlier classes plummets as it learns new classes. Over the last 3–5 years, a variety of strategies have emerged to tackle this stability–plasticity dilemma. These methods can be broadly grouped into: (1) **Replay-based approaches* that store or generate exemplars from past tasks to rehearse and avoid forgetting; (2) *Regularization and knowledge distillation* methods that constrain updates to preserve prior knowledge (often exemplar-free); (3) *Parameter isolation or expansion* techniques that allocate separate model components per task or selectively freeze/expand parts of the network; and (4) *Model merging and ensemble* strategies that combine parameters or predictions from multiple task-specific models. We focus on recent strong papers in each category, especially those demonstrating high performance on benchmarks like Split CIFAR-100 and ImageNet subsets (e.g. ImageNet-100), and highlight whether they require a replay buffer or not. Table *1* at the end provides a summary comparison of these methods, including their core idea, use of past data, and benchmark results.

## Exemplar Replay and Distillation Approaches 
*Replay-based methods* have proven very effective in CIL, often yielding state-of-the-art performance. These methods maintain a small buffer of past examples (or synthetic examples) and typically use knowledge distillation to retain past knowledge:

- *iCaRL (CVPR 2017)* – A pioneering CIL approach that introduced exemplars and a nearest-mean-of-exemplars classifier ([CVPR 2019 Open Access Repository](https://openaccess.thecvf.com/content_CVPR_2019/html/Hou_Learning_a_Unified_Classifier_Incrementally_via_Rebalancing_CVPR_2019_paper.html#:~:text=crucial%20cause%20to%20this%20problem,incremental%20setting%20of%2010%20phases)). iCaRL stores a fixed number of images per old class and rehearses them while learning new classes. Despite its simplicity, it significantly outperformed naive fine-tuning on benchmarks (e.g. improving accuracy on CIFAR-100 by ~30% over finetune) and remains a strong baseline. However, newer methods have surpassed it by addressing class imbalance and representation drift.

- *LUCIR (CVPR 2019)* – Hou et al. ([CVPR 2019 Open Access Repository](https://openaccess.thecvf.com/content_CVPR_2019/html/Hou_Learning_a_Unified_Classifier_Incrementally_via_Rebalancing_CVPR_2019_paper.html#:~:text=crucial%20cause%20to%20this%20problem,incremental%20setting%20of%2010%20phases)) proposed *Learning a Unified Classifier via Rebalancing (LUCIR), which improved CIL by *cosine normalization of the classifier, a distillation-based “less-forget” loss, and an inter-class margin loss to separate new and old class features. LUCIR uses a small exemplar set (like iCaRL) but mitigates the bias toward new classes. It achieved *state-of-the-art results in 2019* on CIFAR-100 and ImageNet-100, reducing error rates by 6–13% compared to prior methods ([CVPR 2019 Open Access Repository](https://openaccess.thecvf.com/content_CVPR_2019/html/Hou_Learning_a_Unified_Classifier_Incrementally_via_Rebalancing_CVPR_2019_paper.html#:~:text=old%20and%20new%20classes%20uniformly,incremental%20setting%20of%2010%20phases)). An open-source implementation is available ([GitHub - hshustc/CVPR19_Incremental_Learning: Learning a Unified Classifier Incrementally via Rebalancing](https://github.com/hshustc/CVPR19_Incremental_Learning#:~:text=)).

- *BiC (CVPR 2019)* – Wu et al.’s Bias Correction method tackled the problem of biased predictions toward new classes by adding a second-stage training to adjust the classifier’s biases. With a memory of exemplars, *BiC* further improved accuracy (especially in later increments) by learning a calibration parameter on a held-out set ([Rebalancing network with knowledge stability for class incremental ...](https://www.sciencedirect.com/science/article/abs/pii/S0031320324002577#:~:text=Rebalancing%20network%20with%20knowledge%20stability,on%20old%20classes%20in%20CIL)). BiC is often combined with methods like iCaRL or LUCIR for performance gains.

- *PODNet (ECCV 2020)* – Douillard et al. ([[2004.13513] PODNet: Pooled Outputs Distillation for Small-Tasks Incremental Learning](https://arxiv.org/abs/2004.13513#:~:text=setting%20so%20far%20unexplored%20by,available%20at%20this%20https%20URL)) ([[2004.13513] PODNet: Pooled Outputs Distillation for Small-Tasks Incremental Learning](https://arxiv.org/abs/2004.13513#:~:text=art%20models%20on%20three%20datasets%3A,available%20at%20this%20https%20URL)) introduced *PODNet, which approaches incremental learning as a representation learning problem. It uses a *spatial feature distillation loss (Pooled Output Distillation) applied across the network layers to constrain representation change, plus multiple learnable prototype vectors per class to improve adaptability. PODNet with exemplar replay showed excellent long-term performance, maintaining strong accuracy even over many incremental steps. It demonstrated *significant gains* (e.g. +12% on CIFAR-100 and +6.5% on ImageNet-100 over previous state-of-the-art) ([[2004.13513] PODNet: Pooled Outputs Distillation for Small-Tasks Incremental Learning](https://arxiv.org/abs/2004.13513#:~:text=and%20a%20representation%20comprising%20multiple,available%20at%20this%20https%20URL)). Official code is provided by the authors ([[2004.13513] PODNet: Pooled Outputs Distillation for Small-Tasks Incremental Learning](https://arxiv.org/abs/2004.13513#:~:text=art%20models%20on%20three%20datasets%3A,available%20at%20this%20https%20URL)) ([[2004.13513] PODNet: Pooled Outputs Distillation for Small-Tasks Incremental Learning](https://arxiv.org/abs/2004.13513#:~:text=accuracy%20gains%20of%2012,available%20at%20this%20https%20URL)).

- *DER & DER++ (NeurIPS 2020)* – Buzzega et al. proposed *Dark Experience Replay (DER), a simple yet strong baseline that mixes replay with knowledge distillation ([Dark Experience for General Continual Learning: a Strong, Simple Baseline](https://proceedings.neurips.cc/paper/2020/hash/b704ea2c39778f07c617f6b7ce480e9e-Abstract.html#:~:text=offline%20training%20is%20not%20viable,We%20further%20explore%20the)) ([Dark Experience for General Continual Learning: a Strong, Simple Baseline](https://proceedings.neurips.cc/paper/2020/hash/b704ea2c39778f07c617f6b7ce480e9e-Abstract.html#:~:text=either%20gradually%20or%20suddenly,objective%2C%20showing%20its%20regularization%20being)). DER matches the model’s logits (including “dark knowledge” of non-target class probabilities) from past snapshots during replay, enforcing consistency with past tasks. An enhanced version, *DER++ (or X-DER), further refines this by periodically refreshing the memory and anticipating future classes ([[2201.00766] Class-Incremental Continual Learning into the eXtended DER-verse](https://arxiv.org/abs/2201.00766#:~:text=blending%20sequentially,DER%29)) ([[2201.00766] Class-Incremental Continual Learning into the eXtended DER-verse](https://arxiv.org/abs/2201.00766#:~:text=constantly%20rewrite%20past%20recollections%20and,extensive%20ablation%20studies%20that%20corroborate)). These methods, despite their simplicity, *outperformed many complex approaches* on standard benchmarks (CIFAR-100, miniImageNet) ([[2201.00766] Class-Incremental Continual Learning into the eXtended DER-verse](https://arxiv.org/abs/2201.00766#:~:text=,minima%20in%20continual%20learning%20setups)), often achieving around *70%+ average accuracy on Split CIFAR-100* with a modest buffer. DER++ has become a popular baseline and is integrated in various continual learning libraries.

- *FOSTER (ECCV 2022)* – Wang et al. introduced *Feature bOosting and compresSing in conTinual lEaRning (FOSTER), a two-stage framework inspired by gradient boosting ([[2204.04662] FOSTER: Feature Boosting and Compression for Class-Incremental Learning](https://arxiv.org/abs/2204.04662#:~:text=alleviate%20this%20phenomenon%2C%20whereas%20most,We%20validate%20our)) ([[2204.04662] FOSTER: Feature Boosting and Compression for Class-Incremental Learning](https://arxiv.org/abs/2204.04662#:~:text=the%20gradient%20boosting%20algorithm%20to,art%20performance)). In stage one, FOSTER **dynamically expands* the model with additional parameters to learn the new task’s residuals (the difference between the new task’s optimal output and the current model’s output). In stage two, it uses a distillation process to *compress* the knowledge back into a single model, removing the extra parameters. This allows the model to quickly adapt (via expansion) and then consolidate (via compression). FOSTER achieved state-of-the-art performance on CIFAR-100 and ImageNet-1000 increments, outperforming prior methods by several percentage points ([[2204.04662] FOSTER: Feature Boosting and Compression for Class-Incremental Learning](https://arxiv.org/abs/2204.04662#:~:text=learning%20paradigm%20FOSTER%2C%20empowering%20the,available%20at%3A%20this%20https%20URL)). Notably, it uses a small exemplar memory during distillation. The code is open-sourced for reproduction ([[2204.04662] FOSTER: Feature Boosting and Compression for Class-Incremental Learning](https://arxiv.org/abs/2204.04662#:~:text=distillation%20strategy%20to%20maintain%20the,available%20at%3A%20this%20https%20URL)).

Several other recent replay-based methods incorporate additional tricks – e.g. *Mnemonics (CVPR 2020)* learned better exemplar selection, *ACE (CVPR 2021)* improved replay by adaptive gradient gating, and *Rebalancing techniques* like weight alignment or cosine classifiers – all aiming to push accuracy higher on challenging benchmarks without exploding memory usage. Overall, *exemplar replay* (even a few images per class) combined with knowledge distillation has proven to be a *winning recipe, with methods in this category now achieving **70–80%+ average accuracy* on 10-task Split CIFAR-100 and strong results on ImageNet-100/1000 ([[2004.13513] PODNet: Pooled Outputs Distillation for Small-Tasks Incremental Learning](https://arxiv.org/abs/2004.13513#:~:text=and%20a%20representation%20comprising%20multiple,available%20at%20this%20https%20URL)) ([[2204.04662] FOSTER: Feature Boosting and Compression for Class-Incremental Learning](https://arxiv.org/abs/2204.04662#:~:text=learning%20paradigm%20FOSTER%2C%20empowering%20the,available%20at%3A%20this%20https%20URL)).

## Regularization and Distillation without Replay (Exemplar-Free)
While replay is powerful, some scenarios forbid storing past data (e.g. privacy concerns). *Regularization-based and exemplar-free methods* instead rely on constraints to protect old knowledge or use generative models to simulate past data. These often had lower accuracy historically, but recent advances have narrowed the gap.

- *LwF (Learning without Forgetting, 2016)* – An early exemplar-free method that used knowledge distillation from the previous model’s logits to guide new learning. LwF helps retain prior knowledge to an extent but typically struggles as tasks grow more distinct (since it doesn’t address classifier bias).

- *EWC (Elastic Weight Consolidation, 2017)* – A regularization method that slows down learning on weights important to old tasks by adding a quadratic penalty (weighted by Fisher Information). EWC and similar approaches like MAS and SI pioneered the idea of protecting important parameters. However, on complex vision datasets, pure regularization often *lags behind replay-based methods* (EWC’s efficacy drops when tasks are very different). These techniques alone usually aren’t SOTA on ImageNet or CIFAR-100 increments, though they remain useful as components in larger frameworks (e.g. Fisher weights used in model merging below).

- *Generative Replay (DGR, 2017)* – Shin et al. proposed using a generative model to *produce pseudo-samples* of past tasks, instead of storing real data. A generator (e.g. GAN or VAE) is trained alongside the classifier. At each new task, the model is trained on both new real data and generated examples from old tasks. DGR was effective on simple benchmarks (like MNIST), but on CIFAR/ImageNet its performance depends heavily on generator quality. Recent works have explored improved generators (including diffusion models) and feature-level generation, but purely generative replay still underperforms direct exemplar replay on large-scale datasets due to the difficulty of generating high-fidelity, diverse examples.

- *Semantic Drift Compensation (SDC, CVPR 2021)* – A representative exemplar-free technique by Ahn et al., which addresses the feature drift of old classes. SDC freezes the feature extractor after initial training and only updates the classifier for new classes, then applies a compensation to adjust old class prototypes based on how the feature space shifted ([[PDF] Defying Imbalanced Forgetting in Class Incremental Learning](https://ojs.aaai.org/index.php/AAAI/article/view/29555/30929#:~:text=,of%20old%20and%20new)) ([](https://www.arxiv.org/pdf/2503.16793#:~:text=pseudo,auxiliary%20task%20as%20training%20a)). It improved over naive LwF, but still fell short of exemplar methods.

- *First Session Adaptation (FSA, ICCV 2023)* – Panos et al. introduced *FSA* as a strong replay-free baseline ([[2303.13199] First Session Adaptation: A Strong Replay-Free Baseline for Class-Incremental Learning](https://arxiv.org/abs/2303.13199#:~:text=classification%20head%20and%20the%20feature,consider%20a%20diverse%20selection%20of)) ([[2303.13199] First Session Adaptation: A Strong Replay-Free Baseline for Class-Incremental Learning](https://arxiv.org/abs/2303.13199#:~:text=investigate%20various%20CIL%20settings%20including,the%20benefits%20of%20body%20adaptation)). FSA takes a large pre-trained model (or a model trained on an initial “Session 1” batch of classes) and *freezes the feature extractor* thereafter. For each incremental step, it does not update the backbone at all, only updating the classification head. The classifier is implemented via an analytic Linear Discriminant Analysis (LDA) update, which can incorporate new classes without needing stored data ([[2303.13199] First Session Adaptation: A Strong Replay-Free Baseline for Class-Incremental Learning](https://arxiv.org/abs/2303.13199#:~:text=pre,shot%20setting)). Surprisingly, this simple strategy outperformed many complex approaches in replay-free settings, achieving *state-of-the-art (exemplar-free) accuracy* on 15 of 16 evaluation settings they tested ([[2303.13199] First Session Adaptation: A Strong Replay-Free Baseline for Class-Incremental Learning](https://arxiv.org/abs/2303.13199#:~:text=investigate%20various%20CIL%20settings%20including,the%20benefits%20of%20body%20adaptation)). For example, on CIFAR-100 and ImageNet-100 incremental benchmarks, FSA narrowed the gap to replay-based methods significantly. (If a few *FiLM adapters* are allowed on the backbone, FSA improves even more in low-data regimes ([[2303.13199] First Session Adaptation: A Strong Replay-Free Baseline for Class-Incremental Learning](https://arxiv.org/abs/2303.13199#:~:text=techniques%20in%20high%2Flow,current%20approaches%20to%20continuous%20body)).) FSA highlights that a strong initial representation can carry a lot of continual learning, echoing trends in using pre-trained models.

- *Prompt-Based CIL (L2P, DualPrompt 2022)* – Recent works leverage large pre-trained Vision Transformers and cast CIL as a prompt-learning problem. *L2P (Learning to Prompt for CL)* by Wang et al. (CVPR 2022) keeps a ViT backbone fixed and learns a set of small *prompt vectors* that prepended to the input tokens ([[2112.08654] Learning to Prompt for Continual Learning](https://arxiv.org/abs/2112.08654#:~:text=or%20known%20task%20identity%20at,We%20conduct%20comprehensive%20experiments%20under)) ([[2112.08654] Learning to Prompt for Continual Learning](https://arxiv.org/abs/2112.08654#:~:text=aims%20to%20train%20a%20more,art)). A key innovation is a prompt pool from which a subset of prompts is selected for each task’s inputs, allowing the model to dynamically condition on past knowledge. *DualPrompt* (ICLR 2022) extends this by having global prompts (for shared knowledge) and task-specific prompts. These methods are *exemplar-free* and do not require task identity at inference. L2P showed that even without any replay buffer, it can *match or outperform* prior state-of-the-art methods that used exemplars ([[2112.08654] Learning to Prompt for Continual Learning](https://arxiv.org/abs/2112.08654#:~:text=memory%20space,available%20at%20this%20https%20URL)). For instance, on Split CIFAR-100, L2P’s accuracy was on par with or better than many rehearsal methods, thanks to the strong frozen pre-trained features ([[2112.08654] Learning to Prompt for Continual Learning](https://arxiv.org/abs/2112.08654#:~:text=while%20maintaining%20model%20plasticity,available%20at%20this%20https%20URL)). Prompt-based CL opens a new path to high performance without storing raw data, albeit relying on large pre-trained models. 

In summary, purely regularization or distillation-based methods historically suffered on challenging benchmarks. But by leveraging powerful pre-trained representations (as FSA and L2P do) or analytic tricks, *replay-free CIL* has greatly improved. Still, the very top results on benchmarks often come from methods that either use a little replay or other additional sources of information (e.g. pre-training). Next, we look at approaches that *expand or isolate parameters* for each task.

## Parameter Isolation and Expansion Methods 
Another strategy is to allocate dedicated model capacity to new tasks to avoid interference with old tasks. These methods *avoid weight overwriting* by isolation, at the cost of model size or complexity:

- *Progressive Neural Networks (PNN, 2016)* – One of the first such methods, which *adds a new network column* for each task and connects it to previous ones (freezing old columns). This completely avoids forgetting (since old task parameters are untouched) and allows some knowledge transfer via lateral connections. However, PNN’s downside is unbounded growth – not practical beyond a few tasks or in memory-limited scenarios.

- *PackNet (2018)* and *HAT (2018)* – These methods find ways to reuse model capacity. PackNet prunes and “packs” different tasks into disjoint subsets of weights (using network pruning to free parameters). HAT (Hard Attention to the Task) learns binary masks on weights to isolate tasks. Such approaches prevent forgetting and keep a single model, but can be complex to tune and may under-utilize capacity, leading to lower accuracy on new tasks.

- *Supermask Superposition (SupSup, NeurIPS 2020)* – Wortsman et al. proposed learning binary masks (supermasks) to overlay multiple tasks in one network without weight updates. While conceptually interesting (no weight ever changes, only masks), on challenging datasets like CIFAR-100 the performance was poor (e.g. under 20% accuracy reported in some settings) ([Split Cifar 10 | SERP AI](https://serp.ai/posts/split-cifar-10/#:~:text=Split%20Cifar%2010%20,suggests%20that%20direct%20input)). This shows pure isolation without learning new representations can severely limit plasticity.

- *Dynamic Expansion with Consolidation* – Recent works try to expand a model when needed and then consolidate to control growth. We already saw FOSTER (2022) which expands-and-compresses each task’s residual. Another example is *DER (Dynamic Expandable Representation, ECCV 2020)* by Yan et al. (not to be confused with Buzzega’s DER), which added neurons per class and used knowledge distillation to limit forgetting. *CN-DPM (NeurIPS 2021)* expanded a mixture of experts per new class in a data-efficient way. These achieved better accuracy than fixed-capacity regularization methods by giving the model more room to grow, at the expense of extra computation.

- *Pre-Trained Backbone + Adaptation* – A modern interpretation of parameter isolation is using a frozen backbone (pre-trained on a large dataset) and only learning small task-specific adapters. We saw examples like FSA (which freezes after first session) and prompt-based methods. Another notable approach is *LAMOL (2021)* and *GPT-Adapter (2023)* in NLP, or in vision the use of *feature adapters* and *incremental classifiers* on a fixed feature extractor. These avoid forgetting in the backbone entirely. The trade-off is that if the initial representation is not sufficient for new tasks, performance can suffer; but if it is sufficient, this strategy shines. With the rise of foundation models, fixed backbone + small learnable modules has become a viable CIL approach combining strengths of isolation and efficiency.

In practice, pure parameter-isolation (without any cross-task knowledge) often plateaus in accuracy, so many expansion methods *mix in distillation or limited replay* to maintain performance. For example, FOSTER uses distillation, and some expansion methods also keep exemplars to refine the new modules. Overall, parameter-isolation gives strong immunity to forgetting and is attractive for systems where memory of past data is disallowed, but to reach top performance on image classification benchmarks, most current methods still rely on either replay or pre-trained features.

## Model Merging and Ensemble Strategies 
A newer line of research in continual learning is *model merging or weight ensembling. Instead of training one model continually, these methods **train separate models for each task (or snapshot)* and then combine them into a single model for inference. This leverages the idea of *mode connectivity* – different task-specific models might lie in the same loss basin and can be connected in weight space. Merging approaches aim to preserve each task’s performance by carefully fusing parameters:

- *Model Soup & WiSE-FT (2022)* – While not originally proposed for CL, Wortsman et al. showed that simple weight averaging of multiple fine-tuned models (a “model soup”) can improve performance on each task and robustness ([](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/09002.pdf#:~:text=a%29%20WiSE,the%20weights%20of%20the%20current)) ([](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/09002.pdf#:~:text=of%20WA%20for%20CL,between%20OOD%20performance%20and%20target)). WiSE-FT averaged a zero-shot CLIP model with a task-tuned model to balance robustness and adaptation ([](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/09002.pdf#:~:text=in%02vestigated%20the%20application%20of%20weight,Here%2C%20the%20resulting%20ensemble)). These works inspired the idea that *linear combinations of task models* might retain multi-task accuracy. However, naive averaging can fail if tasks are very different, as weights may interfere destructively unless the models are in or near a common mode.

- *Co-Merging (CoMA, CoFiMA 2024)* – Weighted ensemble models are strong continual learners by Marouf et al. (ECCV 2024) formalized this into a continual learning method ([[2312.08977] Weighted Ensemble Models Are Strong Continual Learners](https://arxiv.org/abs/2312.08977#:~:text=%28i,Both%20variants%20are%20conceptually%20simple)). They propose *Continual Model Averaging (CoMA): after training on a new task, they linearly combine the new model with the previous merged model using a weighting factor ([[2312.08977] Weighted Ensemble Models Are Strong Continual Learners](https://arxiv.org/abs/2312.08977#:~:text=%28i,ensemble%20by%20leveraging%20the%20Fisher)). This factor is tuned to ensure the new task is learned (plasticity) without straying too far from the previous weights (stability). They further introduce **CoFiMA (Continual Fisher-weighted Model Averaging), which applies a *per-parameter weighting based on Fisher Information ([[2312.08977] Weighted Ensemble Models Are Strong Continual Learners](https://arxiv.org/abs/2312.08977#:~:text=Continual%20Model%20Averaging%20,at%3A%20%2016%20this%20https)). Intuitively, parameters that were important for past tasks (high Fisher) are given less drift (the averaging leans more toward the old value for those), while less important parameters can shift more towards the new task’s value. Both CoMA and CoFiMA are simple to implement and require no replay data – they just need to store the previous model (or a copy of its weights/Fisher info). The authors report that CoFiMA achieves *state-of-the-art results* on standard benchmarks like CIFAR-100 and miniImageNet, outperforming many prior methods that fine-tune pre-trained models ([[2312.08977] Weighted Ensemble Models Are Strong Continual Learners](https://arxiv.org/abs/2312.08977#:~:text=configuration%2C%20ensuring%20stability,at%3A%20%2016%20this%20https)) ([[2312.08977] Weighted Ensemble Models Are Strong Continual Learners](https://arxiv.org/abs/2312.08977#:~:text=weighs%20each%20parameter%20in%20the,at%3A%20%2016%20this%20https)). Code is available for reproducibility ([[2312.08977] Weighted Ensemble Models Are Strong Continual Learners](https://arxiv.org/abs/2312.08977#:~:text=configuration%2C%20ensuring%20stability,at%3A%20%2016%20this%20https)). This suggests model merging can be a powerful paradigm for CL.

- *MagMax (ECCV 2024)* – Marczak et al. explored model merging for large pre-trained models ([[2407.06322] MagMax: Leveraging Model Merging for Seamless Continual Learning](https://arxiv.org/abs/2407.06322#:~:text=,More)) ([[2407.06322] MagMax: Leveraging Model Merging for Seamless Continual Learning](https://arxiv.org/abs/2407.06322#:~:text=surprisingly%20hold%20up%20well%20in,this%20URL%3A%20this%20https%20URL)). Their approach *MagMax* first fine-tunes the pre-trained model on each new task sequentially (which alone would cause forgetting), but then performs a merging step: for each network parameter, choose the value (from either the current fine-tuned model or a past model) that has *maximum magnitude* ([[2407.06322] MagMax: Leveraging Model Merging for Seamless Continual Learning](https://arxiv.org/abs/2407.06322#:~:text=,More)) ([[2407.06322] MagMax: Leveraging Model Merging for Seamless Continual Learning](https://arxiv.org/abs/2407.06322#:~:text=learn%20from%20new%20data%20without,Our)). The idea is that large-magnitude weights carry important features; by taking the max magnitude across versions, MagMax keeps important contributions from both old and new models. They found that surprisingly, even simpler strategies (like random selection or plain averaging) work decently in some CL settings ([[2407.06322] MagMax: Leveraging Model Merging for Seamless Continual Learning](https://arxiv.org/abs/2407.06322#:~:text=task%20training%2C%20MagMax%20combines%20sequential,The%20code%20is)). MagMax, however, was more robust and showed *superior performance* on both class-incremental and domain-incremental scenarios ([[2407.06322] MagMax: Leveraging Model Merging for Seamless Continual Learning](https://arxiv.org/abs/2407.06322#:~:text=surprisingly%20hold%20up%20well%20in,this%20URL%3A%20this%20https%20URL)). It particularly focuses on making pre-trained transformers continually learn (e.g. CLIP or ViT backbones). MagMax also forgoes any rehearsal data and instead banks on the pre-trained model’s strength and clever weight fusion. The official repository is provided by the authors ([[2407.06322] MagMax: Leveraging Model Merging for Seamless Continual Learning](https://arxiv.org/abs/2407.06322#:~:text=surprisingly%20hold%20up%20well%20in,this%20URL%3A%20this%20https%20URL)).

- *Mode Connectivity Path Merging (2025)* – The provided document itself introduces *Mode Path Fusion (MPF), which constructs a *low-loss path between task models in weight space and then merges along that path ([ACFrOgDhefG4I_qbHS2aKv89VanDduz7yKt-tuVXqnr2Tsz7OpicHChtj7clNsd1Iv0ZZXxY8Z-TjD4gSYv8oce7On1gXJN4zCkwm6fAwGCB6bxl2j6qMg-4CI2eB8iHLJ_rTOCpfD7BJxOCQSsmlLpwJdah45dOzCQGHRc2tBkGe_fpSrltVvDl8Ki6kJMzbPk9w3lKN2M7Ixve0J5i.pdf](file://file-RKWCaMCqeeTfb9DV3UbpmT#::text=without%20succumbing%20to%20catastrophic%20forgetting,specific%20performance%20while%20integrating%20multiple)). Unlike simple linear averaging, MPF finds a nonlinear trajectory through weight space that connects the task-specific optima (leveraging mode connectivity theory ([ACFrOgDhefG4I_qbHS2aKv89VanDduz7yKt-tuVXqnr2Tsz7OpicHChtj7clNsd1Iv0ZZXxY8Z-TjD4gSYv8oce7On1gXJN4zCkwm6fAwGCB6bxl2j6qMg-4CI2eB8iHLJ_rTOCpfD7BJxOCQSsmlLpwJdah45dOzCQGHRc2tBkGe_fpSrltVvDl8Ki6kJMzbPk9w3lKN2M7Ixve0J5i.pdf](file://file-RKWCaMCqeeTfb9DV3UbpmT#::text=The%20concept%20of%20mode%20connectivity,mode%20connectivity%20has%20since%20been))). This can better preserve each task’s performance when merging. MPF is a novel contribution and aims to integrate multiple models without catastrophic interference, by optimizing the merge path to keep loss low on all tasks. This approach, along with CoFiMA and MagMax, represents the cutting-edge of *model fusion in continual learning* – an exciting direction that sidesteps the need for storing old data, at the cost of keeping multiple models (or snapshots) and performing additional optimization for fusion.

Ensemble-based approaches (another related idea) include techniques like *Learned Expert Ensembles* (where each task has its own expert and a gating mechanism decides which expert to use at inference). While ensembles trivially avoid forgetting (just keep old models intact), the challenge is combining their predictions for a unified output. Some methods train a meta-learner or use knowledge distillation to blend ensemble outputs into a single network gradually. These can work well, but usually require storing all past models or a growing number of experts, which can be memory-intensive. Model merging, in contrast, tries to *collapse multiple models back into one* of the same size, which is more scalable if done successfully.

## Conclusion 
In the past few years, the *state of the art in class-incremental learning* has rapidly advanced. On benchmarks like CIFAR-100 and ImageNet subsets, methods employing a mix of replay and distillation (e.g. PODNet, DER++, FOSTER) have achieved strong results, often reaching 70–80% average accuracy where early methods were below 50%. At the same time, *innovations in replay-free learning* (leveraging powerful pre-trained models or clever optimization) have closed much of the gap, which is encouraging for data-constrained scenarios. 

The emerging trend of *model fusion techniques* (CoFiMA, MagMax, MPF) is particularly promising for continual learning: these allow models to *remember by construction*, sidestepping interference by combining knowledge post-hoc rather than imposing strict constraints during training. Early evidence shows they can attain competitive or superior performance ([[2312.08977] Weighted Ensemble Models Are Strong Continual Learners](https://arxiv.org/abs/2312.08977#:~:text=configuration%2C%20ensuring%20stability,at%3A%20%2016%20this%20https)) ([[2407.06322] MagMax: Leveraging Model Merging for Seamless Continual Learning](https://arxiv.org/abs/2407.06322#:~:text=surprisingly%20hold%20up%20well%20in,this%20URL%3A%20this%20https%20URL)), making them valuable baselines (and complements) to compare with the Mode Path Fusion (MPF) approach in the provided work. Each approach comes with trade-offs – e.g. replay methods use extra memory, prompt/adapters rely on large pre-training, merging methods require storing multiple model copies – so evaluating a new method like MPF against this spectrum of SOTA techniques will illuminate its strengths in retaining knowledge, accuracy on new tasks, and resource efficiency. 

Overall, the *CIL landscape* now spans from memory-intensive but straightforward replay methods to sophisticated weight-space manipulations, and benchmarking against a diverse set of these state-of-the-art methods (with and without replay) will ensure a comprehensive assessment of MPF’s design trade-offs and performance. The referenced papers and code implementations provide a strong foundation for such comparisons ([[2004.13513] PODNet: Pooled Outputs Distillation for Small-Tasks Incremental Learning](https://arxiv.org/abs/2004.13513#:~:text=art%20models%20on%20three%20datasets%3A,available%20at%20this%20https%20URL)) ([[2312.08977] Weighted Ensemble Models Are Strong Continual Learners](https://arxiv.org/abs/2312.08977#:~:text=configuration%2C%20ensuring%20stability,at%3A%20%2016%20this%20https)), and they represent the current frontiers of continual learning research.
